# PhotoFrame AI

PhotoFrame is a video-to-image frame extraction application.

## Features

- Upload videos
- Extract frames at different time intervals
- Preview extracted frames
- Select individual frames
- Select all frames
- Download selected frames as ZIP

## Technology

- Python
- Flask
- FFmpeg
- HTML
- CSS
- JavaScript

## Deployment

This project uses Docker and Render.
